# Product Vision

## Product category

Agent Exposure Management (AEM)

## Positioning

RIG Sentinel is not intended to be another prompt-injection detector, generic MCP firewall, SIEM, EDR, or CNAPP.

Its role is to create a vendor-neutral security graph for agentic systems and answer:

- Which agents exist?
- Who owns them?
- Which identities do they use?
- Which tools and systems can they reach?
- Which sensitive data can they access?
- Which combinations of permissions create dangerous attack paths?
- What is the blast radius of a compromised agent?
- Which permissions can be removed or constrained?

## Differentiation

The core differentiator is cross-platform relationship intelligence rather than packet inspection alone.

RIG Sentinel should connect information from agent frameworks, MCP, APIs, SaaS, identity providers, cloud services, repositories, and security tooling into one graph.

## Product loop

1. Discover assets.
2. Map identities, permissions, tools, systems, and data.
3. Analyze effective access and attack paths.
4. Rank exposure and blast radius.
5. Recommend least-privilege remediations.
6. Generate policies or pull requests where possible.
7. Preserve evidence for audit and change tracking.
