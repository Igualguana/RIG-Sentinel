# Security Policy

RIG Sentinel is an experimental static-analysis tool. It does not block agent behavior or prove that credentials are shared.

## Reporting vulnerabilities

Please do **not** disclose working exploits, secrets, or sensitive customer data in public issues. Contact the repository maintainer privately through a GitHub security advisory (if enabled) or another private channel explicitly published by the maintainer. If no private channel is configured, request one without disclosing details.

## Supported versions

Only the latest published release candidate is actively maintained during Phase 1. No long-term support promise is made.

## Report safety

Review JSON, HTML, and SARIF outputs before sharing. Repository paths, credential names, and other metadata may be sensitive. No production secrets should be used in test fixtures.
