# Contributing to RIG Sentinel

1. Open an issue describing the proposed change (avoid disclosing security vulnerabilities publicly).
2. Create a branch from `main`; do not commit credentials or real customer code.
3. Run `python -m pytest -q` and add tests for new detection logic.
4. Submit a Pull Request explaining behavior, limitations, and false-positive impact.
5. Keep changes focused; preserve existing CLI and JSON compatibility.

See `SECURITY.md` for vulnerability reports.
